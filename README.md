# Divulgare Arti Marziali

Progetto di ricerca e divulgazione: rendere esplicita, analizzabile e trasmissibile
la competenza motoria delle arti marziali — oggi in larga parte tacita — attraverso
un modello formale del movimento.

Il primo caso di studio è il **pugno**: non per dimostrare che una tecnica è
"quella corretta", ma per costruire un metodo che descriva *perché* una certa
organizzazione del movimento è vantaggiosa, sotto quali condizioni, e se quelle
condizioni sono misurabili.

## Struttura

| File/dir | Ruolo |
|---|---|
| `wiki/` | La conoscenza del progetto. Partire da `wiki/INDEX.md`. |
| `tools/` | Strumenti di supporto. `biomech-editor.html` = lavagna biomeccanica v0 (aprire nel browser). |
| `CANON.md` | Decisioni accettate. Solo con approvazione esplicita. |
| `RICHIESTE.md` | Richieste esplicite del Director, con le sue parole. |
| `SESSION_HANDOFF.md` | Stato del lavoro tra una sessione e l'altra. |

## Principi guida (sintesi)

1. **Osservazione ≠ interpretazione ≠ ipotesi.** Ogni affermazione sul movimento
   dichiara il suo livello epistemico.
2. **L'esperienza genera ipotesi, non prove.** ~30 anni di pratica e ~15 di
   insegnamento sono il generatore di ipotesi, non la validazione.
3. **L'ottimo è l'output utile sotto vincoli**, non la massima forza/velocità/
   massa efficace.
4. **Lean.** Si aggiunge struttura solo quando un'esigenza reale la richiede.
